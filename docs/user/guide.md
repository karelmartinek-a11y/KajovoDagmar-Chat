# Uživatelská příručka

Po přihlášení se otevře Chat. Mikrofon se aktivuje pouze tlačítkem **Zahájit rozhovor**; stav vždy ukazuje orb i text. Odpověď lze přerušit, mikrofon pozastavit a konečný přepis opravit. Textové zadání používá stejný kontext.

Historie globálně hledá minulé relace, zobrazuje úplný přepis a umožní navázat novou propojenou relací. Paměť je oddělená: položku lze výslovně uložit, upravit, označit neaktuálně, sloučit, odstranit a po retenční dobu obnovit. Profil obsahuje e-mail, heslo a aktivní relace. Nastavení obsahuje všechny provozně měnitelné hodnoty, poskytovatele, hlas, soukromí, diagnostiku a zálohy.
