# Rozšiřování

Nová schopnost nejprve mění SSOT. Návrh zaznamená účel, datový dopad, API/realtime kontrakt, bezpečnost, konfiguraci, vypnutí, migraci, kompatibilitu, testy, observability, zálohu a návrat. Výchozím místem je nový modul stávajícího monolitu; samostatná služba vyžaduje výslovnou změnu kanonické architektury.
